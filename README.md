# Planilha de Declaração de Imposto de Renda

Projeto desenvolvido durante o curso de Excel e IA com Claude, com o objetivo de facilitar a organização das informações financeiras utilizadas na preparação da declaração do Imposto de Renda.

## Sobre o projeto

A planilha foi criada no Excel para reunir informações do titular, informes bancários e entradas financeiras em um único arquivo, facilitando o preenchimento e a consulta dos dados.

## Funcionalidades

- **Dados do titular:** espaço para preenchimento das informações pessoais e cadastrais.
- **Informes bancários:** registro dos valores informados pelos bancos e identificação dos documentos anexados.
- **Entradas financeiras:** organização dos registros por data, categoria e valor.
- **Cálculos automáticos:** utilização de fórmulas para somar os valores registrados.
- **Lista de bancos:** aba auxiliar com nomes e códigos das instituições financeiras.

## Ferramentas utilizadas

- Microsoft Excel
- Fórmulas do Excel
- Organização e estruturação de dados

## Objetivo do aprendizado

Praticar os recursos do Excel na criação de uma planilha funcional, utilizando fórmulas e organização de dados para facilitar o controle das informações financeiras.

## Observação

A planilha serve como apoio à organização dos dados e não substitui o programa oficial da Receita Federal.
